# 小鹅通助手

一个 Manifest V3 Chrome 扩展，用来把小鹅通鹅圈子帖子的正文、附件、一级评论、回复评论和评论媒体打包成一个 ZIP 文件。

## 导出内容

- `index.html`：离线阅读版，可直接用浏览器打开
- `帖子.md`：Markdown 格式的正文、附件目录和评论树
- `post.json`：结构化帖子与评论数据
- `files/`：帖子附件
- `media/`：帖子及评论里的图片、音频和视频

扩展会分页读取全部一级评论，并为每条一级评论继续分页读取全部回复。任一附件或媒体下载失败时，扩展会停止导出并显示错误，避免生成看似成功但内容不完整的压缩包。

## 安装

```bash
npm install
npm run build
```

然后打开 `chrome://extensions`：

1. 开启右上角“开发者模式”。
2. 点击“加载已解压的扩展程序”。
3. 选择本项目的 `dist/` 目录。

## 使用

1. 登录并打开鹅圈子。
2. 在帖子列表中点击目标帖子右下方的“打包下载”；也可以进入帖子详情页后，从扩展弹窗点击“打包当前帖子”。
3. 等待浏览器开始下载 ZIP。

## 隐私

- 数据和压缩包全部在浏览器本地处理，不会上传到任何服务器。
- 导出内容保留页面可见的作者、时间和 IP 属地，但会排除接口中的精确 IP、内部用户 ID、企业账号标识等隐藏字段。
- 扩展只申请鹅圈子和小鹅通常用静态资源域名的访问权限，不申请 `<all_urls>`。
