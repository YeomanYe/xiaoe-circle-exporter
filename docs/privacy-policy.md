# 小鹅通助手隐私政策

更新日期：2026-08-15

小鹅通助手是一个 Chrome / Edge 浏览器扩展，用于在用户主动操作时，将小鹅通鹅圈子帖子正文、附件、评论和评论媒体打包下载为 ZIP 文件。

## 数据处理

- 扩展只在用户打开鹅圈子页面并主动点击“打包下载”或“打包当前帖子”时运行。
- 扩展会读取当前帖子页面中可见或接口返回的帖子内容、附件、评论、回复评论和评论媒体，用于在本机生成 ZIP 文件。
- 扩展不会把读取到的帖子内容、评论、附件、媒体或账号信息上传到开发者服务器或第三方服务器。
- 扩展不会收集、出售、共享或转移用户数据。

## 权限用途

- `activeTab`：在用户当前打开的鹅圈子页面上执行导出操作。
- `tabs`：识别当前页面、打开临时帖子详情页、在导出完成后关闭临时页面，并根据当前页面更新扩展图标状态。
- `scripting`：在鹅圈子帖子详情页中执行数据读取脚本。
- `downloads`：把本机生成的 ZIP 文件保存到浏览器下载目录。
- `offscreen`：在 Manifest V3 的离屏文档中生成 ZIP 文件。
- `host_permissions`：访问鹅圈子页面、小鹅通接口和帖子附件/评论媒体资源，用于完整下载用户主动导出的内容。

## 远程代码

扩展不加载或执行远程托管代码。所有扩展脚本随扩展包一起分发。
